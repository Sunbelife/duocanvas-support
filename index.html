两面 · DuoCanvas

外屏一张封面，内屏一句喜欢的话。

为支持相机外屏的 iPhone Duo 设计。选择默认书封、自定义书封、自己的照片或微信读书书架封面，再为内屏选一句诗，或写下自己的文字。

使用方法

展开 Duo，在左侧选择风格，右侧始终预览后屏效果。点文字配置项打开编辑弹窗，修改即时更新。点「开始」进入展示模式，双击内屏可显示或隐藏结束按钮。

后屏为什么需要相机权限？

后屏显示依赖系统相机采集辅助界面。应用在前台开启后置相机会话，但不展示取景器，不读取、保存或上传摄像头画面，也不采集声音。系统相机隐私指示灯保持显示。切换至后台时采集停止。

微信读书

微信读书为可选功能。按引导在微信读书官方设置中获取 Skills API Key，再回到两面完成验证，即可选择自己书架中的封面。可在管理页删除本机授权。两面是独立应用，与微信读书无隶属或官方合作关系。
